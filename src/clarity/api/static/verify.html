Enter the receipt number from an SMS, a PDF, or a QR code.

How this check works

Every receipt is signed with an Ed25519 key and linked to the receipt issued before it. This page recomputes the receipt's hash, checks the signature against the published public key, and confirms the link is intact. Nothing secret is needed, so a customer, an agent on 1788, or a regulator can all run the same check. A receipt that was altered, or never issued by Hutch, fails here.
