## What changed
- Customer sign-in uses the mobile login artwork from `UI/Mobile Clarity app login.png`, then the number and the 6-digit code.
- A wrong code shakes the field, clears it, and says how many attempts are left. After three refusals the field is disabled.
- Clarity Desk sign-in is side by side on a desktop: the desk artwork on the left, staff ID and password on the right.
- Titles use Google Sans. All other text uses Google Sans Flex. Both are OFL-1.1 and self-hosted. Inter and Space Grotesk are no longer loaded.

## Why
The UI directory mockups are the sign-in layout. Customer sign-in stays number plus OTP. The server already burns a code after three wrong guesses (`MAX_ATTEMPTS`).

## Decisions made
- No password path and no "Use OTP instead" on the customer screen. OTP is the sign-in.
- Remember me and forgot password are not on the desk. There is no API for them.
- The step-up code stays. Approvals above the cap still ask for it.
- Titles are Google Sans, the face on the desk heading. Body text is Google Sans Flex.
